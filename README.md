# Playground

Eine kindgerechte Lernspiel-App mit kleinen Spielen für Mathe, Sprache und Logik.

## Lokal starten

```bash
npm install
npm run dev
```

Danach http://localhost:3000 öffnen.

## Build prüfen

```bash
npm run build
```

## Technik

- Next.js 15
- React 19
- TypeScript
- Spielsterne werden lokal im Browser via LocalStorage gespeichert.

Es wird derzeit keine Datenbank und kein Backend verwendet.
